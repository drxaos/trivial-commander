# TCM (Trivial Commander) — двухпанельный файловый менеджер

## Запуск

```bash
mvn package                     # соберёт target/tcm-1.0.0.jar (shade, все зависимости внутри)
java -jar target/tcm-1.0.0.jar
```

Либо в IDE: запустить `tcm.Main`. Полный список клавиш — `F1` в программе.

### Native image (GraalVM)

```bash
GRAALVM_HOME=../graalvm-25.4.4.1.1 mvn -Pnative package   # ~5 мин, target/tcm + lib*.so (AWT)
target/tcm
```

Исполняемый файл запускается только вместе с библиотеками `lib*.so` из `target/`: это AWT и шрифты JDK,
их надо переносить вместе с ним. Метаданные рефлексии/JNI/ресурсов лежат в
`src/main/resources/META-INF/native-image/tcm/tcm/` и собраны агентом
(`java -agentlib:native-image-agent=config-merge-dir=...`) при прогоне всех окон во всех темах.
Если добавляется новый код, который обращается к классам через рефлексию, агент нужно прогнать заново.
Все UI-делегаты, рамки и иконки FlatLaf из его `.properties` зарегистрированы целиком: агент видит только то,
что показывалось во время прогона (так потерялся `FlatToolTipUI`). Сложный текст (эмодзи, комбинируемые диакритики,
иврит, арабский, деванагари, тайский) JDK 25 раскладывает через HarfBuzz по FFM: его downcall/upcall лежат в секции
`foreign`, их пишет агент на файлах с такими именами.
Для перепрогона нужен чистый `user.home`: иначе JVM берёт шрифты из кэша `~/.java/fonts`,
и агент не записывает JNI-вызовы fontconfig.

## Возможности

- **Две панели** с таблицей Name / Ext / Size / Date / Attr, сортировка кликом по заголовку или `Ctrl+F3..F7`,
  краткий/подробный вид (`Ctrl+F1`/`Ctrl+F2`), миниатюры (`Ctrl+Shift+F1`), скрытые файлы (`Ctrl+H`),
  фильтры (`Ctrl+F10` все, `Ctrl+F11` программы, `Ctrl+F12` своя маска), быстрый фильтр/поиск (`Ctrl+S`, `Ctrl+Alt+буква`).
- **Вкладки** (`Ctrl+T`/`Ctrl+Shift+T` — новая/фоновая, `Ctrl+W`/`Ctrl+Shift+W` — закрыть/остальные, `Ctrl+Tab`, список `Ctrl+Shift+A`),
  двойной щелчок по пустому месту справа от вкладок — дубль текущей, средняя кнопка (колесо) на вкладке — закрыть; вкладки в одну строку (не шире 200 px,
  полный путь — в подсказке), полоса прокручивается колесом мыши,
  история `Alt+←/→`, `Alt+↓`, избранные каталоги `Ctrl+D`, дерево каталогов `Alt+F10`, обмен панелей `Ctrl+U`/`Ctrl+Shift+U`,
  каталог другой панели в активную — `Ctrl+=` (меню Commands и кнопка на тулбаре).
- **Автообновление**: панели перечитываются при возврате фокуса в окно и не чаще раза в секунду при изменениях
  в открытых на них локальных каталогах (WatchService) — например, видно, как растёт скачиваемый файл.
  Курсор, отметки, прокрутка и переименование в панели при этом не сбиваются; результаты поиска не перечитываются.
- **Файловые операции**: копирование (`F5`, `Shift+F5` — в тот же каталог), перемещение (`F6`), переименование в панели (`Shift+F6`),
  групповое переименование (`Ctrl+M`), каталог (`F7`, `Shift+F7` — в другой панели), удаление в корзину/навсегда (`F8`/`Shift+F8`, `Del`/`Shift+Del`),
  символические ссылки (`Ctrl+Shift+F5`), буфер обмена файлов (`Ctrl+C`/`Ctrl+X`/`Ctrl+V`, совместим с системным).
  Очередь операций (`F2 Queue` в диалоге), прогресс с Pause / Background / Cancel, конфликты Overwrite / All / Skip / Skip all
  (в диалоге перезаписи `F3`/`Shift+F3` — просмотр, `Ctrl+F3` — сравнение).
- **ZIP и JAR как каталоги**: вход по Enter, копирование/перемещение/удаление/переименование внутри архива (архив перезаписывается
  атомарно), упаковка (`Alt+F5`, `Alt+Shift+F5` — с удалением), распаковка (`Alt+F9`/`Alt+F6`), проверка CRC (`Alt+Shift+F9`).
  Имена без флага UTF-8 читаются как DOS: CP866, если они русские, иначе CP437.
- **TAR, TAR.GZ/TGZ, TAR.BZ2, TAR.XZ, RAR (RAR4/RAR5)** — только чтение: просмотр содержимого, просмотр файлов,
  копирование из архива, распаковка, проверка. Сжатый TAR распаковывается во временный `.tar` один раз
  (как в TC). `Ctrl+PgDn` открывает как архив любой файл: формат определяется по сигнатуре (`.docx`, `.apk`, `.cbr`...).
  `Enter`/двойной щелчок по файлу без связанной программы делает то же самое.
  Имена записей с `..` обрезаются, поэтому распаковка не может выйти за каталог назначения.
- **Поиск** (`Alt+F7`): маска или RegEx имени, текст (подстрока/RegEx, регистр, «НЕ содержащие»), глубина, архивы,
  размер/дата/тип на вкладке Advanced, поиск в найденном (`F2`), история результатов (`Alt+←/→`); «Feed to listbox», «Go to file».
  Плоский список подкаталогов — `Ctrl+B`.
- **Просмотр** (`F3`, Viewer): текст (UTF-8/BOM, fallback ISO-8859-1; `A`/`S` — 1251/866), двоичный, hex, HTML;
  поиск `F7`/`F3`, переход между файлами `N`/`P`. Быстрый просмотр `Ctrl+Q` (в другой панели) и `Ctrl+Shift+Q` (окно).
  Меню как в TC: File (Save as, Reload `F2`, Close), Edit (Copy, Select all, Find `F7`, Find next `F5`),
  Options (режимы `1`–`7`, Markdown `8`, JSON `9`, ANSI `A`, ASCII `S`, другая кодировка, пропорциональный шрифт `V`, перенос `W`,
  курсор `F6`),
  Image, Help (`F1`). Для изображения недоступны Edit и Options, для текста — Image.
  Markdown (CommonMark и таблицы GFM) показывается размеченным, `.md` — сразу; сырой HTML выводится текстом,
  картинки из сети не загружаются, ссылки http/https открываются в браузере.
  JSON `9` показывается с отступами (pretty-print); разбор нестрогий, так что и обрезанный или битый JSON форматируется.
  Колесо мыши, прокрученное с нажатым колесом, листает в 5 раз больше строк.
  Чтение и преобразование файла (раскодирование, hex, разметка) идут в фоне: главное окно не ждёт, а закрытое окно просмотра
  (и редактора) отменяет загрузку.
  Строки длиннее 10000 символов в текстовых режимах переносятся: одна строка в мегабайты иначе надолго занимала бы окно.
- **Изображения** в Viewer:
  - колесо мыши — масштаб относительно точки под курсором; перетаскивание левой кнопкой — прокрутка;
  - `←`/`→` — соседнее изображение каталога;
  - `Ctrl+C` — копировать изображение в буфер;
  - меню **Image** (в строке меню и по правой кнопке): Zoom (1:1, Fit, In, Out), Flip (Horizontal `H`, Vertical `Shift+H`),
    Rotate (CW `R`, CCW `Shift+R`).
- **Мышь в панели**:
  - нажатие правой кнопки отмечает файл, протягивание правой кнопкой — несколько файлов; удержание правой кнопки 1 с — контекстное меню;
  - удержание правой кнопки на пустом месте — меню каталога: New (Folder, File), Terminal, Explore (файловый менеджер), Properties;
  - перетаскивание файлов за пределы окна — в другую программу (копирование; только файлы с диска, не из архива);
  - щелчок по кнопке `F8 Delete` с `Shift` — удалить, минуя корзину;
- **Change attributes** (контекстное меню файла, меню Files): права rwx владельца/группы/остальных (в Windows — атрибуты DOS),
  дата изменения, обработка содержимого каталогов. Нетронутая отметка не меняет атрибут, серая — у выбранных значения разные.
- Кнопка **Terminal** на панели инструментов открывает терминал в каталоге активной панели.
  - перетаскивание левой кнопкой в другую панель (или на каталог) открывает диалог копирования; каталог, куда упадут файлы,
    обведён рамкой; пока во время перетаскивания нажата правая кнопка — перемещение, отпустили — снова копирование;
  - отмеченный файл тянет за собой все отмеченные, неотмеченный — только себя;
  - файлы, брошенные из другой программы (файлового менеджера, рабочего стола), — диалог копирования в каталог под мышью
    или в текущий каталог панели (только копирование);
  - двойной щелчок по разделителю панелей ставит его ровно посередине, в окне шириной до 1200 px он всегда посередине;
  - кнопки `\` `..` `~` над панелью — корень, вверх, домой.
- **Размеры каталогов**: `Пробел` на каталоге, `Alt+Shift+Enter` — все каталоги текущей панели по очереди (и пункт меню Files).
  Сочетания с Alt+Shift (Ctrl+Shift) работают и при переключении раскладки этими клавишами (XKB `grp:alt_shift_toggle`):
  модификатор, съеденный переключением, восстанавливается по нажатиям самих клавиш (`LayoutSwitchKeys`).
- **Редактор** (`F4`, `Shift+F4` — новый файл, имя под курсором подставляется в запрос): сохранение `F2`/`Ctrl+S`
  в исходной кодировке, в т.ч. внутрь архива; undo, поиск, `Ctrl+G`.
  Меню File (Save, Save as, Reload, Close) и Edit (Copy, Select all, Find, Find next).
- **Сравнение содержимого** (`Ctrl+Shift+F3`): два файла рядом, LCS-diff, различия красным, `Alt+↑/↓`, синхронная прокрутка,
  двухстрочная панель `F9`. Сравнение списков файлов панелей — `Shift+F2`.
- **Командная строка**: `cd`, `md`, `rd` встроены, остальное — в окне-консоли (stdout/stderr, stdin, Stop) в каталоге активной панели;
  буквы из панели уходят в строку, строка — выпадающий список истории (стрелка справа, `Alt+F8`, `Ctrl+↓`), `Ctrl+E` — предыдущая команда,
  `Ctrl+Enter`/`Ctrl+P` — имя/путь в строку.
- **Темы** FlatLaf (Configuration): Light, Dark, IntelliJ, Darcula. Состояние окна, вкладок и истории сохраняется (`java.util.prefs`) при выходе (и по `Cmd+Q` на macOS) и раз в 30 с.

### Клавиши

Раскладка взята из справочника TC (`shortcuts.html`); не реализованы сетевые функции (FTP, LPT/USB), плагины,
синхронизация каталогов, комментарии `descript.ion` и навигационные цепочки. Отличия от TC:

| Клавиша | Здесь | В TC |
|---|---|---|
| `Ctrl+Shift+F3` | сравнение по содержимому | в главном окне не назначено |
| `Ctrl+H` | показать/скрыть скрытые файлы | не назначено |

## Структура

```
src/main/java/tcm/
  Main.java               точка входа, темы FlatLaf
  MainFrame               меню, тулбар, командная строка, F-клавиши, глобальная раскладка клавиш
  FileCommands            команды над файлами (F3–F8, архивы, поиск, сравнение, буфер, запуск)
  core/                   VFile, Vfs ("archive.zip!/entry"), ArchiveIndex, ArchiveFormat (расширение/сигнатура),
                          ArchiveReader, TarArchives, RarArchives, ZipOps (add/remove/rename/extract),
                          Searcher, TreeStats, Trash (корзина freedesktop.org / Desktop)
  ops/                    Job, JobContext (прогресс/пауза/отмена), JobRunner (очередь), Copy/Delete/Pack/Unpack/Test/LinkJob
  ui/                     FilePanel (вкладки), PanelTab, PanelMouse (жесты мыши), PanelDrop/PanelExport (файлы из ОС и в ОС),
                          LayoutSwitchKeys (модификаторы при смене раскладки),
                          FileTable, FileTableModel, QuickBar, CommandLine, FileClipboard, иконки
  ui/dialogs/             копирование, перезапись, прогресс, упаковка, поиск, дерево, групповое переименование, свойства, справка
  apps/                   просмотрщик (ViewerPanel/ViewerWindow, ImageView), редактор, сравнение, консоль
  util/                   кодировки, маски, diff (Хиршберг), настройки, Keys
```

## Smoke-тест (без GUI)

```bash
mvn compile
java -cp "target/classes:$(mvn dependency:build-classpath -q -Dmdep.outputFile=/dev/stdout)" tcm.SmokeTest
```

Проверяет: листинг, копирование локально/в архив/из архива/внутри архива, перезапись, упаковку, удаление записей,
mkdir и переименование внутри архива, перемещение, распаковку, JAR, поиск (маска, глубина, текст, RegEx, архивы, размер),
подсчёт размера, проверку CRC архивов, символические ссылки, защиту от zip-slip, DOS-имена в ZIP (CP866/CP437), маски, diff, кодировки,
TAR/TAR.GZ/TGZ/TAR.BZ2/TAR.XZ/RAR5 (листинг, чтение, распаковка, проверка, запрет записи, битый gzip), открытие по сигнатуре.
